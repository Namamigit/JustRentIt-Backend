# JustRentIt Backend

Backend service for JustRentIt – a Full Stack Ethnic Wear Rental Platform.

## Tech Stack
- Java
- Spring Boot
- Spring REST
- MySQL
- Gradle
- Docker

## Features
- User authentication
- REST API integration
- Booking management
- Inventory workflow
- Backend database connectivity

## Tools Used
- IntelliJ IDEA
- Postman
- Git/GitHub
- Docker
